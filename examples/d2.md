# D2 diagrams

Each fenced `d2` block is rendered to SVG on the server. A standalone version lives in [network.d2](network.d2).

## Basic shapes and connections

```d2
direction: right

user: User {shape: person}
app: Web app
db: Database {shape: cylinder}

user -> app: requests
app -> db: queries
db -> app: rows
```

## Containers

```d2
cloud: Cloud {
  web: Web tier
  api: API tier
  web -> api
}

client: Client
client -> cloud.web: HTTPS
```

## SQL tables

```d2
users: users {
  shape: sql_table
  id: int {constraint: primary_key}
  name: varchar(100)
}

orders: orders {
  shape: sql_table
  id: int {constraint: primary_key}
  user_id: int {constraint: foreign_key}
  total: decimal
}

orders.user_id -> users.id
```

## Sequence diagram

```d2
shape: sequence_diagram

browser: Browser
server: Server
db: Database

browser -> server: GET /doc
server -> db: load
db -> server: content
server -> browser: HTML
```

## ELK layout

This block selects ELK in its source, so "Auto" in the Layout menu renders it with ELK. Pick "dagre" to compare.

```d2
vars: {
  d2-config: {
    layout-engine: elk
  }
}

client -> api: request
api -> auth: verify
api -> cache: lookup
cache -> db: miss
api -> db: query
```
