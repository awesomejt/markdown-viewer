# Setup

Start here, then read the [advanced topics](advanced/README.md).

## Installing

Point `MDV_ROOTS` at a folder of Markdown files and start the server.

```bash
MDV_ROOTS=examples=./examples ./build/mdv
```

## Checking

Open the examples index in a browser: [examples index](../README.md).
